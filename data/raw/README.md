\# 原始数据说明



本文件夹用于保存项目使用的原始数据。



\## 数据文件



本地文件名：



`Online Retail.xlsx`



由于原始数据文件体积较大，本文件不会上传至GitHub。需要运行本项目时，应从官方来源下载并放置到当前文件夹。



\## 数据来源



UCI Machine Learning Repository：



https://archive.ics.uci.edu/dataset/352/online+retail



推荐引用：



Chen, D. (2015). Online Retail \[Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33



## 数据概况



- 文件格式：Microsoft Excel
- 官方记录数：541,909
- 数据时间范围：2010-12-01至2011-12-09
- 数据主体：一家英国在线零售企业
- 主要业务：礼品销售
- 货币单位：英镑
- 许可协议：CC BY 4.0



## 使用规则



1\. 原始文件只用于读取，不直接修改。

2\. 数据清洗通过Python代码完成。

3\. 清洗后的数据保存到`data/processed`。

4\. 项目中的所有数据处理规则都需要保留文字和代码记录。

5\. 数据集实际质量以项目审计结果为准，不完全依赖网站元数据。
