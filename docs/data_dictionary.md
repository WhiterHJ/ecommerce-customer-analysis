# 数据字典

## 一、数据集概况

- 数据集名称：Online Retail
- 数据来源：UCI Machine Learning Repository
- 原始文件：`Online Retail.xlsx`
- 文件格式：Excel
- 官方记录数：541,909
- 字段数量：8
- 时间范围：2010-12-01至2011-12-09
- 数据主体：英国在线零售企业
- 货币单位：英镑
- 许可协议：CC BY 4.0
- 数据来源地址：https://archive.ics.uci.edu/dataset/352/online+retail

## 二、数据粒度

根据初步观察，一行数据代表一个订单中的一条商品明细，不代表一个完整订单。

同一个`InvoiceNo`可以重复出现在多行中，因为一个订单可能包含多个商品。

因此，后续计算订单量时，需要对`InvoiceNo`去重计数，不能直接使用数据行数。

## 三、字段说明

| 字段 | 中文含义 | 初步类型 | 业务含义 | 后续需要检查 |
|---|---|---|---|---|
| InvoiceNo | 订单或发票编号 | 分类/文本 | 标识一笔订单；以C开头时官方说明为取消订单 | 是否重复、取消订单数量、是否缺失 |
| StockCode | 商品编号 | 分类/文本 | 标识不同商品 | 是否存在特殊编码、是否缺失 |
| Description | 商品描述 | 文本 | 商品名称或描述 | 是否缺失、同一商品是否存在不同描述 |
| Quantity | 商品数量 | 整数 | 当前订单明细中的商品数量 | 是否存在0、负数或极端值 |
| InvoiceDate | 交易时间 | 日期时间 | 订单产生的日期和时间 | 时间范围、格式、是否缺失 |
| UnitPrice | 商品单价 | 小数 | 商品单位价格，货币单位为英镑 | 是否存在0、负数或极端值 |
| CustomerID | 客户编号 | 分类/文本 | 标识不同客户 | 是否缺失、读取后是否变成小数 |
| Country | 国家或地区 | 分类/文本 | 客户所在国家或地区 | 是否缺失、名称是否统一 |

## 四、官方规则

UCI官方说明指出：

- `InvoiceNo`通常是一个6位编号。
- 当`InvoiceNo`以字母C开头时，表示取消交易。
- `StockCode`用于标识商品。
- `Quantity`表示当前订单明细的商品数量。
- `UnitPrice`的单位为英镑。
- `CustomerID`用于标识客户。
- `Country`表示客户所在国家或地区。

## 五、需要通过实际数据验证的问题

以下问题暂时不作结论，将在数据审计阶段验证：

1. 实际是否存在缺失值。
2. 是否存在完全重复的数据行。
3. 数量是否存在0、负数或极端值。
4. 单价是否存在0、负数或极端值。
5. 以C开头的订单是否都对应负数量。
6. 是否存在没有客户编号的交易。
7. 同一个商品编号是否存在多个商品描述。
8. 是否存在邮费、银行费用或人工调整等特殊商品编码。
9. 数据实际时间范围是否与官方说明一致。
10. 一个订单平均包含多少条商品明细。
