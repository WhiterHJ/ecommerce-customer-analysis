# SQL业务分析结果

## 一、分析目的

本阶段使用MySQL对清洗后的电商交易数据进行业务分析，主要回答以下问题：

1. 整体销售规模如何？
2. 销售额和订单量如何随月份变化？
3. 哪些国家和地区贡献了主要销售额？
4. 哪些商品销量和销售额较高？
5. 取消交易的规模如何？
6. 客户复购和客户价值集中度如何？

具体指标口径见[业务指标口径说明](metric_definitions.md)，查询代码见：

- [总体经营指标查询](../sql/03_overview_metrics.sql)
- [综合业务分析查询](../sql/04_business_analysis.sql)

## 四、月度销售趋势

月度销售额存在明显波动。2011年1月和2月销售额连续下降，3月恢复增长，4月再次下降。此后整体呈波动上升趋势。

在完整月份中：

- 2011年5月销售额环比增长43.27%。
- 2011年9月销售额环比增长39.40%。
- 2011年11月销售额达到£1,503,866.78，是数据范围内销售额最高的完整月份。
- 2011年11月共有2,769个销售订单，也是订单量最高的月份。
- 2011年12月销售额为£637,790.33，但该月只有9天数据，不能据此判断销售额大幅下降。

年末销售增长可能与节日消费有关，但数据只覆盖一个完整年度，暂时不能将其确定为稳定的季节性规律。

英国贡献了全部正常销售额的84.59%，说明企业的销售市场高度集中于本土。

荷兰和澳大利亚的订单量相对较少，但平均订单金额较高，可能包含批发型或大额采购客户。

挪威共有36个销售订单，销售额为£36,165.44，平均订单金额为£1,004.60。其特点应表述为“订单量较少但平均订单金额较高”，而不是简单表述为海外销售额最高的市场。

## 六、商品表现

按照销售额计算，商品编号`22423`的销售额最高：

- 商品：REGENCY CAKESTAND 3 TIER
- 销售数量：13,851件
- 涉及订单：1,988单
- 销售额：£174,156.54

商品编号`23843`共销售80,995件，销售额为£168,469.60，但这些数量只来自一个订单。这是一笔明显的大额交易，可能显著影响商品销量排名，后续分析时应单独核查，不能直接把它解释为普遍市场需求。

商品分析使用`stock_code`作为主要商品标识，`description`只用于辅助展示，避免商品描述大小写或文字差异造成重复统计。

## 八、客户与复购分析

客户分析只包含具有`customer_id`的正常销售记录。

| 只购买一次的客户 | 1,493名 |
| 复购客户 | 2,845名 |
| 复购客户占比 | 65.58% |

| 全部可识别客户销售额 | £8,887,208.89 |

可识别客户中约三分之二发生过复购，说明现有客户群具有一定重复购买特征。

前10名客户贡献了可识别客户销售额的17.30%。客户价值存在一定集中，但销售额并未完全依赖极少数客户。

## 九、主要结论

1. 英国贡献84.59%的正常销售额，是企业的核心市场，同时也反映出较高的市场集中度。
2. 2011年下半年销售额整体增强，11月达到最高点，但只有一个年度的数据，不能确认长期季节性。
3. 荷兰、澳大利亚和部分北欧市场订单量不高，但平均订单金额较高，值得进一步分析其批发客户特征。
4. 可识别客户复购率为65.58%，客户复购是后续RFM客户价值分析的重要基础。
5. 取消金额约占正常销售额的8.40%，应继续关注高取消金额商品和客户。
6. 部分商品排名受到单笔超大订单影响，需要将异常大额交易与普通零售需求区分解释。

## 十、分析限制

- 2011年12月只有9天数据，不能与完整月份直接比较。
- 部分正常销售记录缺少客户编号，客户分析只代表可识别客户。
- 数据没有成本和利润字段，因此销售额不能解释为利润。
- 取消交易记录不等同于已完成退款。
- 个别超大数量订单可能影响商品和客户排名。
- 数据来自一家英国非实体店零售企业，结论不能直接代表整个电商行业。
